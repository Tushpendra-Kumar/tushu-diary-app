# Design System

## Current Design (Black & Gold Premium)
- **Theme Identity**: Dark-neutral with warm gold accents.
- **Base Background**: `#050505` (True Deep Black).
- **Cards/Surfaces**: `rgba(10, 10, 10, 0.75)` with `rgba(240, 165, 0, 0.35)` borders.
- **Primary Color (Gold)**: `#F0A500`
- **Text Colors**: 
  - Primary: `#FFFFFF`
  - Secondary: `#D0D0D0`
  - Muted: `#606060`
- **Glow Effects**: Radial glowing orbs (`rgba(240, 165, 0, 0.05)`) and particle effects via `ParticleBackground.js`.
- **Search Bar**: Integrates seamlessly with no harsh white web focus outlines (`outlineStyle: 'none'`).

## Component Specifications
- **Border Radius**: Generally `16px` for cards and modals.
- **Grid Layout**: 2-column format with `45%` width and `2.5%` margin per card.
- **Bottom Tabs**: Height `68px`, dark background, gold accent on active tab.
