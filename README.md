## 🌟 Executive Overview & Purpose

In today's fast-paced digital world, personal life management is chaotic. People juggle 6 to 8 different apps just to manage daily life: one for notes, one for khata/udhaar, one for daily expenses, one for medicine reminders, another for grocery lists, a password manager, and yet another for vehicle service logs. Most of these commercial apps sell user data, bombard screens with aggressive ads, or lock basic features behind expensive monthly subscriptions.

**TushuDiary** is an all-in-one, ultra-secure, offline-first personal operating system and digital life companion engineered by **CodeByTushu**. It unifies every aspect of personal, household, and financial life into a unified, privacy-respecting native Android application with zero recurring monthly subscription traps.

Download `TushuDiary.apk` from the official **CodeByTushu** website or receive it directly via WhatsApp / Drive.

## 🛠️ Technology Stack & System Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                      FRONTEND LAYER                         │
│  React Native (0.86) • Expo (57) • React 19 • Lucide Icons │
│      Offline-First Architecture with Local AsyncStorage     │

                               │ REST APIs / JWT
┌──────────────────────────────▼──────────────────────────────┐
│                       BACKEND LAYER                         │
│       Node.js • Express.js • SQLite3 • Firebase Auth        │
│       Role-Based Access Control (Admin vs Normal User)      │
└─────────────────────────────────────────────────────────────┘
```

* **Frontend**: React Native, Expo SDK ~57, React 19.
* **Styling**: Custom Luxury Dark Theme with Liquid Gold Accents, Smooth Glassmorphism, and Particle Effects.
* **Data Persistence**: Local-First `AsyncStorage` for zero-latency instant offline usability.
* **Security**: `crypto-js` (AES-256), `expo-local-authentication` (Biometrics/PIN).
* **Backend**: Node.js, Express.js, SQLite (`database/tushudiary.sqlite`).
* **Authentication**: Email/Password + Firebase OAuth (Google, Apple, GitHub, Facebook).
* **Admin Exclusivity**: Role-gated portal strictly restricted to `tushpendrakumar@gmail.com`.

## 👨‍💻 Developer & Build Instructions

### Method A: Build APK in Android Studio (Recommended)
1. Double-click **`open-in-android-studio.bat`** in the project root.
2. Once Android Studio finishes syncing, navigate to top menu:  
   `Build` ➔ `Build Bundle(s) / APK(s)` ➔ `Build APK(s)`
3. Once completed, run **`copy-latest-apk.bat`** to copy the generated APK directly into the root folder as `TushuDiary.apk`.

### Method B: 1-Click Fast APK Build (Terminal / CLI)
Run the automated script in the root directory:
```cmd
build-apk.bat
```
This automatically compiles Hermes JavaScript bundle, links native C++ libraries with Ninja/CMake, assembles the release APK, and places it at `E:\TushuDiary\TushuDiary.apk`.

### Method C: Run in Local Development Mode
```bash
# 1. Start Mobile App (Web/Expo)
cd mobile
npx expo start -c --web

# 2. Start Backend API Server
cd backend
node server.js
```
